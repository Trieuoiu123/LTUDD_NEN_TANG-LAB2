Tổng hợp bài giảng về Progressive Web App

SLIDE 1

5 Criteria of a PWA (5 Tiêu chí PWA)

📱
Installable: Thêm vào màn hình chính với icon khởi chạy độc lập như app Native.
🔌
Offline-First: Hoạt động ổn định không cần kết nối mạng qua Service Worker + Cache API.
⚡
Fast & Responsive: Khởi động dưới 1 giây từ local cache, tối ưu cho mọi kích thước màn hình mobile.
🔔
Engaging: Hỗ trợ Web Push notifications và Badging API.
🔒
Secure: Truyền tải an toàn qua HTTPS.
SLIDE 2

PWA vs. Native App Comparison

Bảng so sánh chi tiết giữa Progressive Web App và Native Mobile App

Feature Progressive Web App Native Mobile App
Distribution Direct URL / Web Link Google Play / App Store
App Store Fee 0% Fee 15% – 30% Fee
Updates Instant (via Service Worker) Store Review (1–3 Days)
Bundle Size 1 – 5 MB 25 – 80 MB
Hardware Access Good (Camera, GPS, Storage) Full (BLE, NFC, Biometrics)
Offline Support Cache API + IndexedDB Local SQLite / File System
SLIDE 3

Service Worker Lifecycle (Vòng đời SW)

1. Register in main.js: Khởi tạo đăng ký Service Worker từ file JavaScript chính.
2. ( Install Event ): Pre-cache core App Shell assets (HTML, CSS, JS, Icons) vào CacheStorage.
3. ( Activate Event ): Dọn dẹp phiên bản cache cũ bị deprecated và tiếp quản điều khiển.
4. ( Fetch Event ): Intercept HTTP requests và áp dụng các chiến lược Caching.
SLIDE 4

5 Core Caching Strategies

1. Cache-First (App Shell)
Kiểm tra Cache trước; nếu tìm thấy trả về ngay lập tức; nếu không thì fetch từ network. Tối ưu cho giao diện tĩnh.
2. Network-First (Live Data)
Thử gửi network request mới; fallback về Cache khi mất mạng (Offline). Tối ưu cho dữ liệu biến động.
3. Stale-While-Revalidate (Feed)
Trả về ngay kết quả cached cũ đồng thời âm thầm fetch cập nhật mới ở background.
4. Cache-Only
Chỉ truy xuất tài nguyên đã được pre-cache hoàn toàn offline.
5. Network-Only
Truyền thẳng qua network cho các request giao dịch không cache (e.g. Auth Tokens).

Liên Kết Google Sheets (Thời Gian Thực)

Tự động đồng bộ báo cáo khảo sát trực tiếp vào trang tính Google Sheets của bạn.

Các bước tạo Webhook kết nối Google Sheets:
  1. Mở file **Google Sheets** của bạn.
  2. Vào menu **Tiện ích mở rộng (Extensions)** ➔ **Apps Script**.
  3. Dán toàn bộ đoạn mã bên dưới vào và lưu lại (`Ctrl + S`):
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Mã Báo Cáo", "Thời Gian", "Khu Vực", "Mã Phòng", 
        "Loại Thiết Bị", "Tình Trạng", "Mức Ưu Tiên", "Ghi Chú", 
        "GPS", "Người Khảo Sát", "Mã SV/NV", "Trạng Thái"
      ]);
    }
    var gpsStr = data.gps ? (data.gps.latitude + ", " + data.gps.longitude) : "N/A";
    sheet.appendRow([
      data.id || "",
      data.timestamp || new Date().toISOString(),
      data.locationZone || "",
      data.roomCode || "",
      data.facilityType || "",
      data.condition || "",
      data.priority || "",
      data.notes || "",
      gpsStr,
      data.surveyorName || "",
      data.surveyorId || "",
      "VKU PWA Synced"
    ]);
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", error: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Bấm **Triển khai (Deploy)** ➔ **Triển khai dưới dạng ứng dụng web (New Deployment)**.
  2. Tại mục *Ai có quyền truy cập (Who has access)* ➔ Chọn **Bất kỳ ai (Anyone)**.
  3. Copy đường link **URL ứng dụng web** dán vào ô bên trên!
